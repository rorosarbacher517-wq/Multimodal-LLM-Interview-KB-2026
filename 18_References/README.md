### 使用参考文献的面试原则

不需要背 DOI 或 benchmark 小数点。需要知道：**解决什么问题、输入输出是什么、架构改在哪里、训练怎么改、成本怎么变、为什么合理。**

遇到具体层数、模块、尺寸或 2026 新版本信息，回原论文、官方 YAML、源码或官方 release notes 核对，不凭印象回答。
