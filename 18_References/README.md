## 引用原则
不背 DOI 和排行榜小数点。真正要掌握：
1. 解决什么问题；
2. 输入输出；
3. 核心结构；
4. 训练目标；
5. 成本；
6. 相对前代改变什么。

具体层数、参数或 2026 新版本信息，回 primary source 核对，不凭印象回答。
