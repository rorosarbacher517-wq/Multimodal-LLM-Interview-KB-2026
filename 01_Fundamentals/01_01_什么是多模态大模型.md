# 01_什么是多模态大模型

## 面试一句话

多模态大模型不是“LLM 前面挂一个视觉模型”这么简单；核心是把图像、视频、音频等信息转换成 LLM 能联合建模的表示，并在同一生成或推理目标下完成跨模态对齐。

## 核心回答

- 最常见的 Vision-Language 架构可拆成三块：**视觉编码器（Vision Encoder）→ 连接器（Projector/Resampler）→ LLM**。
- 输入图像先变成视觉 token；连接器完成维度对齐和 token 压缩；LLM 再把视觉 token 与文本 token 一起做自回归建模。
- 更进一步的 Omni 模型会同时处理 image/video/audio/text，并可能直接生成 speech，而不只是生成文本。
- 面试时最好按 **模态编码 → token 化 → 对齐/融合 → 语言模型推理 → 输出头** 来回答。

## 常见追问

**Q：VLM、MLLM、Omni model 有什么区别？**

VLM 强调视觉-语言；MLLM 通常指以大语言模型为核心的多模态系统；Omni 更强调多输入模态、甚至多输出模态和实时交互。

## 易错点

- 不要把所有多模态模型都说成“CLIP + LLM”；不同模型的视觉编码器、连接器、融合方式和训练阶段差异很大。
