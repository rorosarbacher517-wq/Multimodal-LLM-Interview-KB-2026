# 08_多模态中的MoE是什么

## 面试一句话

MoE 让每个 token 只激活少数专家，因此可以增加总参数量而不让每个 token 都执行全部 FFN。

## 核心回答

- 典型结构：router 根据 token 表示选择 top-k experts。
- 总参数量和 active parameters 要区分；推理算力更接近 active parameters，但显存仍受总权重影响。
- Llama 4、Qwen3-Omni 等代表性模型采用 MoE 以提高容量/效率比。
- 分布式部署时 MoE 会引入 Expert Parallelism 和 all-to-all 通信问题。
## 易错点

- 不要说 MoE 一定更快；如果路由、通信、batch 很差，吞吐未必更好。
