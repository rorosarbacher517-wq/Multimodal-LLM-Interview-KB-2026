# 09_多模态模型的三种主要瓶颈

## 面试一句话

多模态能力差通常不是单一的“LLM 不够大”，而是 perception、alignment 和 reasoning 三个环节任一处成为瓶颈。

## 核心回答

- Perception：图像细节、OCR、空间定位是否被编码出来。
- Alignment：视觉特征是否被正确映射到语言语义空间。
- Reasoning：模型能否在视觉证据上进行多步推理，而不是靠语言先验猜答案。
- 工程侧还有第四类：视觉 token 太多导致显存、prefill、KV cache 成本过高。
## 易错点

- 分析错误时先定位链路，不要一上来就归因于“训练数据少”。
