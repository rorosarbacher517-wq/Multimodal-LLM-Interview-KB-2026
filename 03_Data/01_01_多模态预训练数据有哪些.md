# 01_多模态预训练数据有哪些

## 面试一句话

多模态数据不能只理解成 image-caption；真正的数据谱系包括配对、交错、OCR/文档、grounding、视频、音频、GUI 和 agent trajectory。

## 核心回答

- Image-text pairs：基础语义对齐。
- Interleaved image-text：学习多图、多轮、文档式上下文。
- OCR/Document：文字识别、表格、版面和文档推理。
- Grounding：bbox/point/region 与文本短语对齐。
- Video/Audio：时间序列与事件级标注。
- Agent trajectory：截图/状态 + action/tool call + 结果。
