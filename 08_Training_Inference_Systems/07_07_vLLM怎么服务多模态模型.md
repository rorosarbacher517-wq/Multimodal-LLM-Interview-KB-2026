# 07_vLLM怎么服务多模态模型

## 面试一句话

现代 vLLM 已支持 text/image/video/audio 等多模态输入，但视觉预处理和 token budget 需要显式管理。

## 核心回答

- 请求先经过 multimodal processor 生成文本 token + multimodal features。
- 服务端需要限制每个 prompt 的图片/视频数量，避免 OOM。
- 大规模场景会缓存处理后的多模态 features。
- 最新文档还提供 disaggregated multimodal serving 示例，把 render/preprocess 与 generate 分开。
